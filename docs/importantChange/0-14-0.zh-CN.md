## 查询方案

### `上下方案查询项内间距`

- `内间距为 8px`
- 如果用的是 Card 组件: `增加size属性`

```tsx | pure
<Card size="small">
  <NormalProgrammeComponent store={normalProgramme} />
</Card>
```

- 其它自己写样式

### [上下方案折叠配置](/jumai-utils/programme/normal-programme#showcollapse)

### `上下方案查询项和表格外间距`

- 内部已经调整间距方案,外部有自写查询项和表格的外间距请去掉
- 主表顶部按钮间距为: 4px(上下查询方案如果自写请更改)

### 页面适配

- 由各业务线自己适配
- 对于页面是通过 iframe 显示的可以在提供首页的页面设置该布局菜单内容的最小宽度和 x 轴超出滚动条(auto)。云仓是在菜单组件的 Layout 加的
- 对于不是通过 iframe 显示的直接在 global.less 设置 body 相关属性
- `去掉原来在页面设置的最小宽度`

### 去掉属性

- filterBase 的 showCollapse、isCollapse、toggleCollapse(只有单选和多选内部用到,外部有更改请去掉)
