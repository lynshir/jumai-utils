## 常见问题

### antd 将要废弃的 props

- 参考控制台 antd 报的警告,有时间就改,5 版本有的会删除

### [Input 的 ref](https://4x.ant.design/changelog-cn#4.19.0)

- Input 的 ref 类型改变,参考上面链接
- 项目中发现有直接使用 ref 的 handleReset 方法,需要重写

### Collapse

- 箭头的位置 props 有改动

### moment

- antd 内部依赖的 moment 和外部 moment 类型不兼容(上面已经更新包)

### select

- `filterOption`类型和原来的不兼容,项目有发现直接用此属性的 children 来做筛选(考虑 options 和 optionFilterProp="label")

### Radio 和 Checkbox

- 可能存在样式问题(原来一行显示的现在折行了)
