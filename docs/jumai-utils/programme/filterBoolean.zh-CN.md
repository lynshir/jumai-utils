## `type`

- 描述: 类型标志
- 类型: 'boolean'
- 默认值: 'boolean'

## `isFormatBoolean`

- 描述: 是否格式化成 boolean 参数
- 类型: boolean
- 默认值: true

## `yesText`

- 描述: true 时的文本
- 类型: string
- 默认值: 是

## `noText`

- 描述: false 时的文本
- 类型: string
- 默认值: 否

## `value`

- 描述: 选择的值
- 类型: '0' | '1'
- 默认值: undefined

## `handleChangeCallback`

- 描述: 值改变回调
- 类型: (value?: string | undefined) => any
- 默认值: undefined
